## What it is

The Discipline Duel is a browser-first game experience for web play that converts mindset and self-improvement into something you can actively play through. Its mechanics center on resilience HP, future focus scoring, and counter-strike responses, so choices, setbacks, and recovery all feed into the outcome.

Built with HTML and JavaScript, the project runs straight in the browser and does not require installation. Scenario paths are generated dynamically, giving each session a different feel while keeping the core loop anchored in discipline, progress tracking, and long-range focus.

## Core Features

- Browser-based gameplay with no installation step
- Resilience HP system that reflects how you handle setbacks
- Future focus scoring to reward forward-looking decisions
- Counter-strike mechanics for responding to challenges
- Dynamic scenario generation to keep sessions varied
- Progress tracking for monitoring ongoing improvement
- HTML5 and JavaScript implementation for web compatibility
- Focused on mindset, discipline, and resilience themes
